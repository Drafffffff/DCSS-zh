# DCSS 显示翻译统一契约

本次实施基于 native edab0e49，保留其后的全部已有改动。目标是替换消息链路，不以截图数量、目录数量或中文字符占比衡量完成率。

## 数据流

业务枚举/数值/状态 → 完整消息 ID 与命名参数 → 语义显示名称 → 选择显示语言 → 原样排版/绘制。

- 固定文字使用稳定 ID；过渡期 zh_source 只接受完整固定源文或不可变数据库正文，带上下文。禁止传入已格式化的英文结果。
- 动态文字使用 zh_message；不从最终英文句子反向提取参数。保留 canonical 与 localized，内部控制/日志规则/Lua/存档取 canonical。
- 人物等级、技能等级、法术等级、变异阶级、地牢深度分别定义 ID/context/参数。通用 integer 类型不代表这些语义可以混用。
- 参数有严格 schema；名字使用语义对象接口；颜色与按键是不可翻译结构。普通 text 不能包揽未迁移的拼接句。
- 固定中文文档/数据库正文在数据读取处选语言，不拆成词句再次匹配。

## 两种作用域

ZhTranslationPause 仅用于规范英文读取、内部数据和旧接口兼容，确实让语言选择返回 canonical。

ZhLegacyPause 仅用于已经选择语言的原样渲染；它阻止旧 matcher，不改变新模板/名称/数据库的语言选择。渲染层不得使用 ZhTranslationPause 代替它。

raw parser/菜单/tooltip 的 pretranslated 标志只表示呈现来源，不能改变输入匹配、数据库 key、Lua 或存档数据。

ZhLegacyGuard 是已迁移模块的开发检查。背景重绘豁免必须登记，不可作为整个模块无旧依赖的证据；最终应按模块消除豁免。

## 模块完成条件

先审查全部主入口、选择菜单、详情、帮助、悬停、成功/失败反馈与渲染出口，再统一修改。固定接口/显示名称/布局修改和文案审校各有归属。

一个模块关闭需同时满足：生产点使用新接口；没有旧匹配回路；所有适用分支有模板或明确登记的语义缺口；真实生成路径、英文内部数据和Mac场景测试通过。仅 raw 渲染通过不等于全部文案完成。

每个批次集中交付 Luna 完整文案包，主 agent 负责代码和测试。Mac 是日常调试基准；Linux 只在阶段冻结后做构建/平台验收。测试只用存档副本。

## 验收和发布

参数、完整模板、颜色/快捷键、缺失、重复翻译、规范英文读取均有自动检查。实际路径检查包括等级/层数、动态战斗、商店余额与颜色、长详情、技能帮助和HUD刷新。

callsites.json 是逐位置审查索引，modules.json 是人工范围与状态。词法候选不是完整AST或完成率。剩余其它生产器必须按此索引继续审查。

旧存档没有 ID 的消息历史单列兼容边界；不得为了宣称无旧接口而破坏原存档，也不得让兼容入口服务新实时消息。

## 共用限制理由与列表

传送、隐形、狂暴和变形的状态判断只维护于共用业务生产器。UI 调用 typed display reason；规范英文消费者从同一结果取 canonical，尚未迁移的父理由保持明确登记。zh_message_list 只组合语义参数，分别组织英文与中文分隔符，并传播每个子项的 supported 状态；未知名称使完整父消息回退并报告，不能对子项再走 matcher。限制提示打印 ZhMessage，确认提示调用 yesno(ZhMessage)，避免丢失规范英文历史或让中文再次进入旧层。
