# Targeting, quiver, spell prompt, and terrain copy review

This batch translates the stable prompt and confirmation fragments requested from the targeting, quiver, spell menu, and movement/terrain producers. Canonical English strings and IDs are copied directly from the request snapshots, with final source-audit additions from targeting and quiver included. Each message has a concrete rendered canonical and Chinese test case; dynamic values use representative runtime-shaped inputs and remain visibly unlocalized where they represent command keys, colors, percentages, or game names.

Targeting help retains the actual controls (`?`, `v`, `.`, `g`, `f`, `Shift`, direction keys) and translates only the action labels. Target prompt prefixes are translated by action type; the monster description bridge preserves an unreviewed child description when its producer has not yet been migrated. Quiver menu controls and markup remain literal. “Quiver” is rendered as “待用” when it means the selected item for repeated use; action-specific labels remain concise, and confused variants state the player condition. Unarmed form actions use established combat wording, while the `key` placeholder remains exactly where the source places it. Spell menu actions use “施放 / 查看说明 / 调整 / 遗忘 / 设为待用”; success and failure prompts use “法术” and “失败风险.” The six risk levels increase consistently from safe through extremely dangerous to dangerously high. Target-effect labels are short fragments because callers append them to spell targeting UI. Polymorph target names retain their runtime color wrapper, while Chinese alternatives use natural list punctuation; the final alternative uses “或” even when the source supplies two names. Root immunity and Sticky Flame adhesion have dedicated concise effect labels. The Enfeeble canonical template includes the source formatter's final “and” between simultaneous effects.

Movement confirmation verbs are concise action stems selected by movement behavior; the surrounding Chinese prompt supplies “进 / 到……上 / 越过” for the source's into, onto, and over cases. This keeps options such as flying, swimming, and wall jumping distinct while preserving the terrain direction and the difference between deep water and lava. “Travel-excluded area” is translated as “旅行排除区域.” Trap names and cloud names are display atoms, not sentence translations; proper names and named traps retain their distinct identity. The passwall messages describe sensed danger beyond the rock without implying that the player has entered it. The typed-answer confirmation keeps the supplied answer key unchanged. A passthrough warning wrapper also preserves an unreviewed legacy warning verbatim, as its producer does not inspect or translate that arbitrary text.

Markup tags, shortcut glyphs, placeholder names, canonical English, and source anchors are preserved. In particular, spell and quiver key markup is runtime control text and must never be translated. Test cases show complete rendered output on both sides and use the sample command key `y`/`a`, `<w>Z</w>`, and `lightcyan` without localizing these structural values. No C++ producer changes are included in this copy review.
