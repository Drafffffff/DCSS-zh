# DCSS 简体中文补译规范（0.34.1）

本目录存放对官方 `language = zh` 译文的**增量补译**。官方译文覆盖约 51.5% 的数据条目，
其余条目以英文回退显示；本补译只填补缺失条目，不修改官方已有译文。

## 硬性规则

1. **键必须逐字符完全一致**。英文条目的键（`%%%%` 之后第一个非注释非空行）原样抄写，
   包括引号、`'5'` 这类字形键、`__SHOUT seen` 这类带后缀的键。
2. 条目格式：
   ```
   %%%%
   英文键原样
   
   中文正文（可多段，段间空行）
   %%%%
   ```
3. **占位符与替换引用原样保留**：
   - `@The_monster@`、`@player_name@`、`@at_foe@`、`@to_foe@`、`@my_God@`、`@shouts@` 等内建替换；
   - `@__KEY@`（同库其他条目）、`@_key_@`（随机替换词组）——这些引用名不要改；
   - 若某引用在中文句子中不自然，可省略该引用，但**不得改动其拼写**。
4. **行首标记保留**：`SOUND:`、`VISUAL:` 必须在其对应消息行开头；`w:N` 权重行原样保留；
   `#` 注释行可保留英文或改写为中文注释（不影响游戏）。
5. `lua` 代码块（`{{ ... }}`）除其中的字符串外不得改动；如有疑问，整块原样复制。
6. 数值、伤害、抗性、百分比、键位（如 `a`、`Tab`）原样保留。
7. 一条英文条目若有多条消息（空行分隔），中文也要有对应数量的消息（顺序一致），
   便于权重对照。
8. 不输出键外的任何英文散文残留；专有名词（如 "Stone Soup"、"Dungeon Crawl"）可保留原文。

## 术语

- 优先沿用官方 `zh/` 语料中的既有译名（可 grep 官方目录）。
- 未出现过的怪物/神/物品名，采用 DCSS 中文社区通用译法；创建新译名时保持全文一致。
- 语气与官方中文一致：说明文用"你/该生物/这个物品"，第二人称叙述。
- 标点使用中文全角；引号使用 “ ”。

## 目录约定

- 补译文件放在 `translations/zh/<descript|database>/<英文文件名>`，内容只含**缺失条目**。
- 安装脚本 `tools/install_zh.py` 会把补译条目追加到游戏 `dat/` 内对应 zh 文件末尾，
  并跳过已存在的键（幂等）。
