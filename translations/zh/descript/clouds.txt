%%%%
smouldering embers cloud

一团阴燃的余烬。任何站在它上面的生物都能轻易将它压熄，
但如果无人理会，它会燃成一团熊熊燃烧的火焰云。
%%%%
alcoholic mist cloud

一片雾化的私酿酒薄雾，浓得生物只要从中走过就可能醉倒。
%%%%
faint pestilence cloud

一丝最微弱的腐臭瘟疫气息，从某处渗出来。
它还没有浓到会造成伤害，但正在迅速变浓。
%%%%
magnetised fragments cloud

一团由无数细小带磁金属碎片组成的云，
因为最近的一次放电仍在微微振动。
在消散之前，它们会充当 Magnavolt 法术的吸引物。
%%%%
bats cloud

一群细小的吸血蝙蝠，密集得无法数清它们的数量。
它们会无情地袭击身处其中的任何非亡灵生物，
用催眠般的撕咬逐渐使对方入睡——并在它们倒下后继续吸食它们无助的身体。
%%%%
rust cloud

一团氧化的水汽云，会不断腐蚀并削弱站在其中的任何生物的攻击
（但只造成极少的伤害）。
