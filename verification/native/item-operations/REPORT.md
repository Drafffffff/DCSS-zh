# 物品操作消息工作包验收

本批在 798db5ea62e769e8e7343038fbaef3f8eb84bf3f 上继续迁移，范围是普通物品操作主链路，并非整个物品、法术或神祇模块完成。游戏文案由 Luna 的拾取/丢弃、装备、使用三个分工审校；主 agent 负责接口、集成、真实生产路径测试和截图。

## 已迁移链路

- 拾取、合并、指定数量、金币及征税后余额、物品栏分配、丢弃成功/失败/地形确认。数量在移动或销毁物品前快照；菜单名称保留原始颜色规则和快捷键。
- 普通穿脱、挥舞、卸下、延迟进度/完成、装备槽与体型/肢体限制、危险换装确认、信仰限制、武器品牌和护甲/首饰效果。旧英文理由 API 保留为兼容包装，已迁移消费者直接传递 typed reason。
- 饮药、读卷轴、魔杖和杂项使用的入口、失败理由、确认、取消与成功消息；附魔/品牌/鉴定回调传递完整 ZhMessage，不再转回英文句子匹配。药水额外覆盖力量、聪慧、吸引、隐形、变异确认及药水真菌反馈；外部法术/变异/神祇效果的其他消息仍另行迁移。
- 隐形药水的光环、污染等来源使用有限语义子消息与结构列表；扭曲武器卸下的传送理由传递完整消息。放逐原因等内部控制数据保持英文。
- 物品选择器无候选理由、默认使用菜单、物品栏分类、替换装备与刻写选择标题接入新接口。自定义旧调用标题仍保留原路径，避免将所有标题误标为已翻译。
- 已鉴定药水/卷轴的 DBNAME、QUALNAME 显示参数使用无数量中文基本名；未鉴定、未知、自定义和部分神器复杂名仍整名或整父句回退并报告，不拼接零碎翻译。

新增参数重命名、数量快照和带颜色的菜单名称辅助接口。枚举名称从语义源读取，未解析最终英文句子。原有英文 wrapper、存档字段、Lua 数据与控制字符串保留。

- 消耗品限制/噪声 6417、共享限制 18670、原样渲染 30、传送/变形 160 与实体传送日志 244、物品教程 405（console/local/web）及全部 51 提示 ID、地形确认 38340 均通过。
- 命名消息验证 6821 检查通过；8581 个已定义 ID 是全仓词库规模，不是本次完成条数或汉化覆盖率。
- Mac 与 Bazzite console 各 10 个存档副本场景通过：拾取、合并、丢弃、挥舞、卸下、脱下、穿戴、金币、饮药、读附魔卷轴。每个场景核对完整绑定译文出现在实际终端输出中，不能只凭 ID trace 验收；缺失 ID/名称均为空。最终满包提示传递修正后追加 Mac 两场、Linux 三场（含库存）通过。

## 明确剩余

1. `items.cc::_identify_last_item` 的最后类别鉴定，`maybe_name_weapon` / `say_farewell_to_weapon` 的专名武器问候与告别，Orb 逃离阶段启动提示、地面集合摘要仍需独立闭环。
2. `player-equip.cc` 的武器/帽子外部数据库低语，以及使用后进入法术、怪物、神祇、状态/变异模块的其他业务消息，未因迁移 use 入口而自动完成。
3. `prompt_invent_item(const char*)` 的其他跨模块自定义提示仍保留旧路径；刻写流程的无物品提示等边缘入口也尚未全部接入。未知/自定义/神器名称的完整回退仍需后续语义覆盖。
4. `delay.cc` 的仆从灌注/伙伴塑形、旅行中断，`quiver.cc` 的部分近战/地形攻击反馈，以及通用欢迎/教程/帮助入口仍在模块账本排队。
5. 本批没有操作 Steam 入口、替换正在运行的程序或发布 Release。构建产物位于独立 QA 输出。

remaining-callsite-candidates.json 是词法审查候选，含已迁移 ZhMessage 变量、内部诊断与调试菜单；不能将候选数直接当未翻译条数。applied-producers.json 同样只是最终调用点清单。后续先处理上述物品语义边缘与跨模块消费者，再按项目账本推进，不称本批为全面迁移或 100% 汉化。
