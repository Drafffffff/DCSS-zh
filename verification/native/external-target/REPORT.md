# 外部目标理由与施法日志迁移验收

本批基线：native `d915a27`，独立仓库 `1ccd325`。源码提交 `e49b923`，地形名称补齐提交 `1f15346`。
文案由 `gpt-6-luna` 子 agent 批量翻译、审校并冻结，主 agent 集成；原始英文和程序控制值保持原义。

## 按项目结构推进

[模块账本](../../../analysis/message-migration/LEDGER.md)保留 13 个模块分组，新增工作包级生产函数、业务消费者、文件、验收和剩余项。源码词法扫描的 6,181 个候选调用点、53 个旧翻译钩子仅用于查漏，均不是汉化率。一个函数迁移不代表整个文件或模块完成。

路线：共用目标理由 → 施法/引导日志 → 法术/瞄准/箭袋提示 → 共用移动与危险地形确认 → 物品操作 → 战斗/实体/状态 → 神祇/角色 → 世界/教程/文档。

## 本批代码范围

- `god-abil.cc`：蹬墙跳的距离、地形、迷惑/恐惧、落点和不可见阻挡理由改为完整模板与专用显示名。
- `spl-other.cc`：穿墙路径五类失败理由；目标预览和实际施法统一使用类型化理由。成功清空复用的显示参数；旧 canonical 包装接口成功时保留原有输出参数行为。
- `spl-damage.cc`：内焰看不见目标、已受内焰影响和无限意志理由；实际施法消费同一结果。
- `spl-summoning.cc`：拟像理由、实际施法免疫提示及精华日志；鳄鱼的地形、目标、后方空间、危险和实际隐藏阻挡。保持隐藏信息规则和原有分支优先级。
- `target.cc/.h`：五类 targeter 直接消费类型化理由，移除 `notify_fail(string)` 及外部英文字符串临时回退分支。保留旧理由 API 的 canonical 包装供兼容；当前调用方已使用显示接口。
- `spl-cast.cc/.h`：施法/魔杖增强、误施法、引导魔力不足、四类引导提醒和停止日志。通过法术枚举选择整句模板，然后替换快捷键；不再传入英文提醒片段。

新增 60 个消息 ID：25 个目标/实际施法消息及语义名称，18 个施法/引导消息，以及真实场景查漏后补齐的 17 类地形名称。目录累计 2,818 个 ID，这是目录规模，不是覆盖率。

## 自动验证

Mac 与 Linux 均通过：49,296 组实际外部理由生产函数对照、100 组真实目标通知生产函数、67 组实际施法/引导生产函数。附加测试从真实 `feat_type_name` 提取全部 17 种输出逐项验证名称支持，避免固定墙壁 stub 遮蔽地面等分支。检查 canonical、分支优先级、可见性、隐藏阻挡、复用参数、完整句回退、状态副作用、静默停止和重绑定按键。

Mac 回归：1,415 组消息 oracle/参数/标记校验、42,493 组法术/护符理由、30,720 组反噬组合、真实数据库读取及 34 个技能选择标签/快捷键通过。

四种原生构建通过：Mac arm64 tiles+sound / console，Bazzite Linux x86_64 tiles+sound / console。最终增量构建日志及二进制 SHA256 随本报告保存。构建保留已有警告；不把警告描述为新增故障。

## 剩余入口与限制

- 同一 `spl-cast.cc` 内的选择、风险描述、列表与箭袋；`directn.cc` 的 `Press` 帮助行仍有英文，已在真实截图中记录为待办。
- `player.cc::check_moveto_terrain` 共用移动/深水/熔岩确认独立迁移；穿墙调用此确认路径，不能据本批路径理由迁移宣称所有穿墙相关提示已完成。
- 其他法术效果、怪物/战斗动态日志、斯芬克斯对白、物品操作、其他教程与复杂显示名仍有待办。
- 53 个公共旧翻译钩子及旧历史/未迁移模块仍保留。已迁移实时路径使用完整模板并绕过旧层，旧词库中的历史条目不作为新消息匹配入口。
- Mac 实机截图为 1747×1112；原生 4K 在 Bazzite 独立 Xvfb 验证，不能宣称 Mac 物理 4K 实机已测。
- 仅使用复制存档，保留源 fixture 哈希；未操作原始角色或正在运行的 Steam 游戏，未覆盖用户安装。两端产物暂存于工作区，未发布新 Release。

## 存档副本与截图验收

Mac 与 Bazzite 终端各通过 7 个场景：蹬墙跳、穿墙、内焰、拟像、鳄鱼目标失败，以及烈焰波和发条蜂的引导提醒/停止。脚本继续读取实际终端输出，逐项断言 Luna 审校的完整中文句已经显示；不会因目标预扫描生成 ID 而提前算通过。两端均无缺失 ID/名称，源存档哈希不变。

Bazzite 独立 Xvfb 原生 3840×2160 通过 5 个截图场景：穿墙、内焰、拟像、鳄鱼及烈焰波。人工查看截图确认目标理由显示为完整中文，消息在地图列内，未侵入物品栏；法师测试模式的调试地形悬停框不计玩家文案。Mac 实机图形副本另查鳄鱼提示及烈焰波提醒/停止，截图为 1747×1112。蹬墙跳/发条蜂的最终 4K 图形场景未单独覆盖，二者有两端终端与生产函数测试。
