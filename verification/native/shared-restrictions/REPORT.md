# 第六批：共用限制理由与传送相关日志

Native 提交：`aa75645d4ec4357e329085e0c27c94c66b2e9c53`。Mac arm64 与 Bazzite x86_64 的 console/SDL 四种构建通过；两端 console 各八场景及 Bazzite 4K 八场景均通过，缺失 ID/名称为零。

本批以 Mac 调试为主，文案由 Luna 审校。四类限制判断集中在业务生产处：传送、隐形、狂暴与变形不再由调用方解析最终英文来取得中文。构建、回放结果与本批提交信息见同目录 summary.json。

## 迁移范围

- player::no_tele_display_reason 按实际限制分支生成带 canonical/localized 的结构化理由。闪现与传送使用两个完整父模板；次元锚、根系、武器、穿戴列表和超过原数量阈值的汇总理由逐一选择模板。物品走 zh_item_arg；列表保留原英文 and/comma，中文独立使用顿号与“及”，任何子名称缺失都整句回退并报告。
- invis_allowed 与 can_go_berserk 增加可选结构化理由输出，PotionEffect、详情和实际操作共用条件顺序。隐形四种光源从固定语义 ID 生成，背光确认走完整 ZhMessage/yesno 重载；确认接受/拒绝、quiet 和 canned message 行为保持原样。
- cant_transform_display_reason 集中变形前置限制；旧 string API 从同一结果取 canonical。木质化药水、flux 唤能理由、变形检查及蝙蝠能力调用新接口。危险地形分别选溺水/灼伤完整模板，降低最大生命值的确认不拼接片段。
- spl-transloc.cc 的无参固定 mpr/mprf 日志以及狂暴启动日志接入稳定 ID；原消息频道保留。17 条实体日志覆盖怪物随传送到达、重力波/束缚/吸引、牵引、空间收缩、维度链接、突进失败与刀刃所有格。单复数和目标类型先选完整模板，再填语义名称与数量。
- 新增 81 条 Luna 审校定义全部绑定，另绑定之前已审校的 15 条隐形/狂暴/变形理由。全目录 2424 条定义、764 个源码字面 ID 绑定均包含其他批次与保留条目，不作为汉化覆盖率。
- 原英文控制、Lua 与存档语义保留。新 mpr 路径同时携带英文历史与中文显示，不把中文写回英文语义字段。通用逐词兜底仍已移除。

## 验证方法

- 18,670 组真实共用理由生产函数回归，和 7648b0b 的英文函数快照比较 canonical、条件优先级、临时/永久、0–6 件装备阈值、未知名称、quiet、yesno 以及日志副作用。世界状态查询为 seam，理由函数和消息运行时使用实际源码。
- 244 组实际动态日志 helper 回归，要求每个 helper 有真实动作调用点；覆盖玩家/怪物、不同名称/标点/数字/所有格、hurl/hurls、数量与地形组合、未知名称整句回退。
- 46 个实际固定日志调用点对照迁移前快照，验证完整英文和消息频道；此检查发现并修复模板末尾标点漂移。另有 946 项消息参数/schema/颜色/快捷键/oracle 检查、6,417 项前批限制/噪声回归、raw 渲染与技能布局回归。
- 副本场景通过向导设置真实状态或实际饮用药水，再进入详情/操作生产路径；没有注入伪造 mpr。每场景独立复制 ZhSmoke 夹具，回放前后校验源夹具 SHA-256。
- Mac 实际窗口截图检查次元锚、树形态限制及详情布局；这些截图不是物理 4K。Bazzite 使用独立 Xvfb 原生 3840×2160 回放；不控制 Steam 中的角色、不覆盖原始存档或正在使用的安装。

## 仍依赖旧层与未解决问题

- no_tele_reason / cant_transform_reason 的 string 包装仍为规范英文消费者保留。spl-util.cc 的外部法术父理由、cannot_put_on_talisman_reason 的完整穿戴流程尚未改为 typed 结果；85 条已审外部法术理由仍在 pending，未编入活动目录。后续需迁移这些父入口才能删除其旧匹配依赖。
- spl-transloc.cc 的动态动作 verb、controlled blink 取消确认、blinkbolt 目标、apport 物品数量、重力方向、猛扑，以及调用方传入 _teleport_player 的英文理由仍待迁移。审计中 helper 调用也被列为候选，候选数不等于实际旧路径数。
- transform.cc 的其他形态进入/离开和装备变化日志、player-act.cc 的其他角色日志，以及其余战斗、装备、拾取、旅行、教学和箭袋入口未在本批全面迁移。不能称为全部日志迁移。
- 复杂神器、未鉴定、自定义或未知名称继续整句回退并报告。旧目录中相同英文条目仍可能由上述未迁移消费者使用；本批新 typed 路径已直接绕过 matcher，不双重翻译。
- 实际截图背景仍可见旧地形/查看命令日志，以及教学 `<input>` 标记问题；本批详情内的限制说明已正常，但这些背景入口尚待后续模块迁移。搜索/着色前缀为程序控制字段，故保持英文。
- 旧公共渲染 hook 审查候选仍有 53 处；不宣称 100% 汉化。
