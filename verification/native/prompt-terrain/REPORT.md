# 瞄准、法术、箭袋提示与危险地形确认迁移

本批按 `target-quiver-prompts`、`terrain-move-confirmation` 两个工作包沿生成函数、调用方和显示出口推进，基线为 native `1f15346`，完成提交为 `0b10e82`。新增和修改的 259 条游戏模板、名称及排版由 Luna 翻译审校；完整词库目前为 3,077 个稳定 ID。这些数量不是汉化覆盖率。

## 已迁移范围

- `directn`：查看/瞄准按键帮助、顶部消息与行为覆盖桥接，按法术枚举选择的目标动作前缀，以及物品目标的专用中文名称。默认前缀、完整父模板和不可翻译控制标记分开。
- `quiver`、`throw`：动作及形态攻击标题、物品/法术/能力名称、充能与失败率、卡牌和建造动作提示、选择菜单与确认提示。`quiver.cc` 已无旧 `zh_translate` 调用；投掷的内部提示仍是规范英文，显示通过 typed 消息桥接，循环切换动作后同样适用。
- `spl-cast`：法术选择及说明菜单、表头/参数/噪声列、菜单动作、重施和风险确认、失败率、瞄准顶部标题与次数、仅对他人有效等提示。中文先选模板再填参数，使用字符显示宽度排版；表头列起点有自动校验。
- 法术目标效果：命中/状态概率、免疫、抗性与特殊状态、衰弱组合、变形候选列表。候选怪物使用显示名称接口，中文列表独立组织；任何未知候选使完整父句回退并报告。`target_spell_desc` 的 Lua 入口显式保留英文。
- `player`、`spl-other`、`prompt`：共用移动危险确认、飞行/形态到期、束缚符印、毒沼、云雾、陷阱、旅行排除区、穿墙目的地确认。保留原判定优先级、接受/取消、Lua 提示及 `yes` 控制输入；typed 确认不再把中文提示截成 200 字节。

## 验证

四种最终构建均通过：Mac arm64 图形版与控制台版，Bazzite x86_64 图形版与控制台版。13 个修改源码文件在四个构建目录的 SHA-256 一致，详见 `source-hashes.json`。构建保留原有编译及 Mac 部署目标/依赖版本警告。

新增实际生成函数测试在两端通过，逐项对照冻结的旧英文生成函数，而非只检查词库：

| 测试 | 实际组合 |
|---|---:|
| 瞄准/箭袋/投掷提示 | 2,214 |
| 施法风险/确认/菜单动作 | 13,837 |
| 法术目标附加效果 | 28,698 |
| 地形/云雾/陷阱/排除区/穿墙确认 | 38,340 |
| 合计 | 83,089 |

另有 1,674 条命名消息及参数/标记/缺失校验通过；详情、技能布局、HUD、原样渲染、限制理由、目标理由、反噬组合、引导日志和教程等回归测试通过。测试输出在 `unit-tests/`。

两端各使用 ZhSmoke 存档副本执行九个实际终端场景：法术普通/参数表、法术瞄准、箭袋菜单、投掷瞄准、束缚符印、警报陷阱、佐特陷阱、技能帮助。新提示场景除核对 ID 外，还将绑定后的完整中文与实际终端输出比较，避免把推测目标产生的 trace 当成已显示消息。无缺失 ID/名称及边界错误，源存档散列不变。

Mac 图形副本实拍验证法术表头/参数列、瞄准风险、箭袋菜单和佐特确认，窗口为 1747×1112；不能将其称为 Mac 原生 4K 验证。Bazzite 独立 Xvfb 原生 3840×2160 图形场景检查相同提示和技能帮助，截图位于 `bazzite-4k/`。所有操作仅针对新建测试进程和存档副本，未进入用户正在游玩的角色，也未覆盖原始存档。
