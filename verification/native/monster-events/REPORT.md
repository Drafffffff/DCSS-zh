# 首遇教程、怪物喊叫与特殊怪物说明迁移

基线 native `303fc53`。本批按账本 `monster-tutorial-shout-special` 迁移完整生产路径；游戏新增、修改文案均由 Luna 翻译审校。消息数量与测试组合数量不作为汉化覆盖率。

## 本批范围

- 首遇怪物提示：Tiles/终端两种正文、终端字形与列表、猎人持弓/未持弓、施法角色，以及异常装备、友好/暂时友好、零经验、离开视野、可见/未见喊叫和无声怪物的相邻教程。模板先选择，名称、字形、颜色与快捷键后填入；保留事件标记、停止移动与教程频道。
- 怪物喊叫：67 个固定数据库叶模板及错误提示。专用 canonical 数据库入口在原始模板选择与递归展开时隔离旧中文数据库，随后按稳定 ID 与怪物事实生成中文。英文替换与随机调用只执行一次，频道、静默判定、噪声和视觉可见性不变。旧数据库接口保留供尚未迁移的玩家谜语等消费者使用。
- 特殊统计正文：特殊抗性、易伤、无定形/酸液反击/冷血等体质和行为、生境、速度与各动作能量、停顿、每回合再生、津恩资格，以及球类和爆炸伤害。删除不再使用的旧抗性词组 helper；保留规范英文接口和业务调用顺序。
- 邻接日志：召唤怪物出现、Wyrmbane 警示、Gozag 煽动进入 typed 消息，保留消息频道和神祇参数。
- 实机场景遗漏：按可见头数事实生成九头蛇名称，修正带自然定冠词的独特怪物名称边界；保持状态/自定义限定词和可见性保护。复用既有中文文档审校四段实际可达图鉴全文。教程怪物标签携带 pretranslated 标志，背景重绘走 raw 格式解析，避免详情窗口重新调用旧匹配器。

## 验证方法

每个场景从独立基准存档再复制一份。玩家原始存档和正在游玩的角色均未打开。重放要求真实生成路径到达、无缺失 ID/名称、无运行异常；终端比较完整参数绑定后的可见中文，不能以 speculative ID trace 代替显示证据。

生产函数测试使用迁移前冻结英文函数、可变事实和真实新函数，检查 canonical 文本、事件标记、频道、噪声、随机调用、副作用顺序与整父回退。另覆盖中英文数据库共存、后缀回退、递归引用、控制值和旧调用隔离，防止仅在英文 stub 上通过。

最终构建、测试、存档哈希和截图结果见 `summary.json`、`source-hashes.json`、`binaries.json` 和相应结果目录。Mac 为实际图形窗口验证；Bazzite 使用独立 3840×2160 虚拟显示，不操作 Steam 中的玩家进程。

## 保留入口与限制

- 随机恶魔/小恶魔嘲讽语法、玩家狮身人面像谜语、其他怪物对白仍待独立协议迁移；未知喊叫模板整句规范英文回退并报告，禁止逐词拼装。
- 其他非怪物教程、变形者神祇警告和其他战斗/角色/物品业务日志尚未迁移完。
- 幽灵/幻象完整生平、恶魔领主形体、变异兽特征旧拼接，外层物品/地形/云雾悬停与部分详情表格既有固定 source 接口（例如护甲值 `none`）仍需后续工作包。详情图鉴四条新增绑定使用既有固定条目 API 的规范展开表示；本批未改造全部 lore 数据库。
- Mac 检查中误选地形曾触发地形 quote 入口的旧中文数据库重复翻译；该入口属于后续世界/地形包，已记录，不能据本批怪物详情验收称其已迁移。
- 现有 Mac 依赖部署版本和未使用常量、Linux 编译器兼容告警保留；本批不调整构建工具链。
- 本批不创建新 Release，也不替换用户 Steam 安装或运行进程。不声称全部详情/全部日志迁移，更不声称 100% 汉化。

## 最终结果

- native 提交：`82239b42b058e6a3e670d8f68ad99bee34c8630b`，15 个源文件，四份源码镜像逐文件 SHA256 一致。
- Luna 新增审校 156 个稳定 ID；目录总计 3543 ID，2160 项参数/完整模板/结构标记 oracle 校验通过。这些数量不是翻译覆盖率。
- Mac arm64 / Linux x86_64 的 Tiles、console 共四种构建通过，并生成独立打包目录；远程与本地 Linux 二进制哈希一致。
- Mac 24 套、Linux 16 套测试均通过。每个平台新增五组真实生产函数对照合计 39525 个组合；冻结英文、副作用顺序与数据库协议同时检查。
- 两端各 15 个存档副本场景通过：9 个本包场景、4 个技能/瞄准/伤势/状态回归、2 个商店选择/购买回归；购买余额 838 校验通过。终端完整父句正文有可见证据，不以 ID trace 代替显示。
- Mac 实际图形窗口检查 4 个截图（1747×1112，未宣称 Mac 原生 4K）；Bazzite 独立原生 3840×2160 显示检查首遇、零经验、九头蛇、酸液团与技能帮助 5 个截图。教程与长详情未越界，技能帮助正文与操作提示在面板内。
- 初始 4K 首遇截图停在 more，后改为推进到正文；伤势回归原先可能零伤害，改为低护甲怪物、多次实际攻击后查看。这是重放输入修正，没有跳过缺失译文或降低完整正文校验。喊叫的验收以两端实际终端可见日志及 Mac 图形视觉喊叫为依据。
- 所有基准存档哈希保持不变。没有操作正在游玩的角色，没有创建 Release 或替换 Steam 安装。

4K 验收限制：喊叫自动截图多次停在非目标日志或历史记录旧页，虽然生成了 ID，尚未可靠取得该条新日志的可见截图；因此不计入本批 4K 图形验收。两端终端的完整绑定喊叫句已可见，Mac 图形视觉喊叫也已截图。后续需完善 SDL 模态输入重放，再增加这一项 4K 图形证据。
