# 消息模板迁移：第一批交付

基于 `dcss-zh/0.34`，保留先前提交与所有 Luna 审校成果。参考同工作区 BROGUE 的 br_tr、生成处动态模板及显示名接口。新增游戏中文均由三个 Luna 分工审校，主 agent 负责协议、集成与验证。

## 已实现

- 稳定消息 ID + context + 命名参数（text/name/integer/number/key/colour），先选完整模板，再填参数。
- 406 个已审校 ID；源码直接字面量绑定 241 个 ID，另外有条件选择 ID 和语义枚举词项。ID 总数不是翻译覆盖率。
- 十个优先模块中 205 处固定消息生成点已接入；主要近战命中/落空/格挡/无伤害/毒伤/活力吸取、人物与技能等级变化、装备动作进度等动态日志接入。
- 商店名称、问候/关闭/感谢、余额/券/不足/购后余额、排序和帮助；物品与怪物详情的一部分数值与命中率，技能提示/训练目标及法术等级。
- 独立显示名接口读取种类、数量、加值、品牌、所有者和鉴定状态；普通名称无法完整构造时整句英文回退并诊断。原 name()、内部标识与存档格式未改。
- 新 mpr 路径在显示与历史回放绕过旧匹配，Lua hook、历史查询、保存继续使用原文。Lua 详情查询暂停时，长说明数据库也取英文。
- 通用逐词兜底与其索引已删除。新层缺失 ID/参数拒绝；不完整显示名以 DCSS_ZH_ID_MISSING / NAME_MISSING 显式报告。

## 验证

- Mac arm64、Bazzite Linux：Console + SDL Tiles 均完成构建。
- 69 项独立 Luna 预期与参数校验；1203 项旧完整模板回归 + 30 项组合模板回归；344 项文字网格/宽字/清屏/裁切/详情表布局校验。
- 验证 ID 唯一性、上下文、参数完整性/类型、静态颜色标签及快捷键；数字包含带符号值、inf/∞。普通缺失译文不允许当作已审校项通过。
- 两端 PTY 真实游戏路径：装备开始/继续/完成、武器数值、技能训练提示；Lua 原文、独立存档保存与正常退出通过。CJK 字符数只用于“窗口确有中文”的烟雾检查，不作为覆盖率。
- Bazzite 3840×2160 共 8 个存档副本场景，实际触发 18 个不同 ID；自动检查战斗、装备、商店、详情所需 ID，且战斗/装备/武器详情无缺失参数。对应 trace 见 final-4k/results.json。程序不是注入已知句子来伪造场景。原始存档前后哈希一致。
- Mac 原生 GUI 详情截图见 macos-weapon-final.png；此机器窗口截图为 1746×1143，未宣称实际 Mac 4K 屏复核。

## 尚未完成，必须继续迁移

- 源码审计仍有 3077 处旧式 mpr/mprf 调用（含诊断等，不等同玩家可见文案数）。完整按文件清单见 inventory.json。
- 旧翻译渲染钩子仍在 output/format/cio/libgui/libunix/menu/precision-menu/directn/quiver/describe/command/纸娃娃等入口。message 的两个旧调用用于尚未迁移消息及旧存档历史。
- 详情和技能 widget 仍混合新旧字符串，最终 parse_string 可二次经过旧层；商店物品行及标题也未完全划清渲染边界。只将新日志 mpr 路径与商店帮助 raw parser 称为已绕开旧匹配。
- 神器、铭文、诅咒、未鉴定物品、复杂怪物名称、物品库存槽位/装备状态描述符尚未全部结构化；安全回退原文。不会把未支持的组合记为已翻译。
- 4K 技能页长帮助在右边缘仍有少量越界字符，需要独立做显示宽度换行；现有网格单元测试并不等于这个旧 widget 已完全适配。
- 物品操作页底部、库存分类、部分目标帮助和状态名称仍有英文；法术效果、远程攻击、特殊战斗附加效果、其余日志与大量 UI 后续处理。
- 旧存档恢复的消息没有 ID/参数，仍使用旧完整模板/片段层。不会改写原存档来制造迁移完成的假象。
- 先前逐词替换预期的测试已归档 legacy-test-before-id-migration.py，移除的是被架构明确禁止的行为断言，替代验证为新独立预期和真实生成路径；不是宣称旧入口全部修好。

这是可构建、经过实际路径验证的第一批迁移，不是全面迁移，也不是 100% 汉化。
