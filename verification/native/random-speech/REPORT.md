# 随机嘲讽、怪物对白协议与引号字体

基线 native `82239b42b058e6a3e670d8f68ad99bee34c8630b`。本包按模块账本 `monster-random-speech` 迁移。游戏新增、修改文案分别由三位 Luna 子 agent 审校；主 agent 负责协议、生成器、集成与验证。目录条数及测试组合数不代表翻译覆盖率。

## 实现边界

- 引入 `ZhSpeech`，记录选中的原始数据库模板、递归子节点、源位置和规范英文。原有加权选择、后缀回退、递归上限、控制字符串及随机调用保持不变。稳定 ID 绑定于原始叶模板，不反向匹配填参后的英文句子。
- 中文完整模板在参数填入之前选择；递归词组、随机分支和频道是独立结构。怪物、玩家、敌对目标、所有格、属名、声音与生成名称经语义参数接口绑定。英文替换及随机选择只执行一次，中文不重新抽签。
- 小恶魔/恶魔随机嘲讽、普通怪物对白选择及显示消费者、逃跑/逼入死角/返回主人/布道，以及 blink-other 两处对白接入新路径。保留未迁移调用需要的旧 API；新路径不读取旧中文 monspeak 数据库。
- 未支持的 Lua、未知模板或语义参数使整条父消息回退规范英文并报告。不会逐词替换，也不把混杂中文当作完成。`god_is` 非无神分支、部分方位别体仍需要后续语义接口。
- 修正弯引号的字体度量：Fusion 中文字形原宽 1200 单位，但终端将这些字符视为单格 600 单位，前引号墨迹因此越过下一格。对四种弯引号仅平移原像素轮廓并修正 advance，不做插值缩放。检查实际发布字体在 24/36/48 像素下均为整数像素、墨迹不越过单格。

## 验证方法

- 测试实际新生产函数和迁移前冻结函数，比较规范英文、RNG 调用、频道、可见性、静默规则、friendly 行为及副作用。不是只运行词库自查。
- 20376 组加权/递归数据库选择和完整嵌套语法；1152 组旧/新消费者组合；25 组实际语义参数；14146 组固定喊叫对照。稳定 ID、命名参数类型及完整性、结构标记和缺失报告同时校验。
- Mac 为主要调试平台。两端使用独立基准存档再复制的副本；源存档前后 SHA256 对比。严格守卫启用，日志中完整中文正文必须可见，不能只凭 ID trace 判定场景通过。
- Mac 图形截图为真实 1747×1112 窗口；Bazzite 图形验证用独立 3840×2160 虚拟显示。后者不是用户 Steam 会话截图。QA 进程结束使用 SIGTERM，清理时记录的 signal 15 不计为运行时崩溃。
- 本轮字体在 Bazzite 使用 QA 专用路径，不覆盖正在使用的 Steam 字体或程序。构建使用原有依赖；Mac dylib 的目标系统版本和 Linux 原有编译告警未在本包处理。

## 未完成入口

- 原始语法审计的 71 条延后记录中，18 条含内嵌 Lua；其余 53 条为纯控制值，不应翻译。Lua 继续只执行一次，尚不能直接把执行结果映射为完整中文模板。
- `mon-cast.cc` 其余施法消息组合、`mon-death.cc` 死亡对白、`mon-abil.cc` 回忆，以及 `god-companions.cc` 使徒挑战/投降/解散等外部 `getSpeakString` 消费者仍需逐包贯通。
- 武器噪声、神祇对白和玩家谜语尚未迁移；其他教程与战斗/角色/物品动态日志继续按模块账本推进。
- 特殊怪物/自定义复杂名称及部分语义别体仍可能触发整父英文回退；本包不宣称所有怪物对白、全部动态日志或 100% 汉化。

最终构建、存档回放和截图结果见 `summary.json`；逐文件来源与二进制校验见 `source-hashes.json`、`binaries.json`。本包不创建 Release、不操作玩家当前角色。

## 最终结果

- native 提交 `798db5ea62e769e8e7343038fbaef3f8eb84bf3f`，15 个源文件的四份构建源码镜像一致。Mac/Linux 的 Tiles、console 四种构建通过；Linux 下载二进制与远程哈希相同。
- Mac 17 套、Linux 4 套针对性测试通过，目录 7624 个稳定 ID 校验通过；3919 个原始模板绑定及 4081 个本轮新增 ID 均不是覆盖率。
- 两端各 8 个存档副本场景通过：固定喊叫、随机嘲讽、兽人对白、技能帮助、技能说明、怪物详情、商店选择及购买；购买余额 838 校验通过。详情回放的场景映射曾触发测试器 KeyError，修正为统一 expected 映射后，对既有真实录制重新执行完整正文校验通过。
- Mac 截图验证真实随机嘲讽和修复后的弯引号。Bazzite 3840×2160 截图补齐固定喊叫、随机嘲讽、普通兽人对白和技能帮助；日志未进入物品栏，技能帮助未越界。兽人初次截图只有提问，重放 20 次实际对白后才取得可见正文，没有以 trace 代替截图。
- 所有基准存档前后哈希一致；未操作当前角色。完整剩余入口见本报告及模块账本。
