# Ranged combat and status message audit (2026-10-17)

Scope: normal player-visible messages in `ranged-attack.cc` and `beam.cc`, with emphasis on projectile/beam misses, blocks, reflections, repulsion, and monster status effects. Compared the existing Luna review files first: the earlier review already contains the generic miss sentence and source-fragment combat verbs; the systematic review covers melee grammar and enemy attack agreement. This pass adds only distinct full ranged/beam runtime forms.

## Findings and added translations

The source still assembles several visible events from dynamic names and English sentence pieces:

- `ranged-attack.cc:161-188` has a finite set of completed forms. The defender's `conj_verb("block")` is `block` for player/plural subjects and `blocks` for singular subjects; the reflection suffix similarly uses `reflect` or `reflects`. Punctuation is either `.`, a visible shield phrase (` with %s %s`), or ` with an invisible shield`; observable reflection adds `... and reflect(s) it back!` to either shield phrase. The catalog now covers the fixed-action combinations with full expanded templates. The identical singular ordinary-block and visible-shield reflection forms are already covered by existing entries. The generic `%s %s the %s%s` form remains excluded because its only fixed anchor is `the`, which can match unrelated menu or help text. For the visible-shield forms, captures retain source argument order: actor, projectile, possessive pronoun, shield name.
- `ranged-attack.cc:211` and `beam.cc:3610` report a repelled projectile as `The %s is repelled.`; added a complete template.
- `ranged-attack.cc:224` formats the projectile, optional evasion-margin adverb, and defender in `The %s%s misses %s.`; added the ranged-specific complete line. The earlier review's generic miss entry does not include this optional adverb slot.
- `beam.cc:5454`, `5462`, and `5474` cover a monster blocking and reflecting a beam with its shield, reflecting a beam from an invisible shield, and an ordinary shield block. Added each complete printf sentence. The four-argument shield sentence is phrased in source argument order (actor, projectile, possessive, shield); the ordinary two-argument block is also checked as actor then projectile.
- `beam.cc:5266` reports loss of fire resistance with `%s fire resistance burns away.`; `%s` comes from `mon->name(DESC_ITS)` and can already be an English possessive phrase such as “The rat's”. The source-shaped entry therefore avoids adding a second 的, and a second normalized complete form `%s's fire resistance burns away.` captures the base monster name. Matching that normalized possessive form against the source's possessive phrase requires rootgrammar possessive support or equivalent source-aware expansion.
- `beam.cc:5691` emits the ordinary monster beam miss through `msg::stream` (`"The "` + beam name + `" misses "` + monster name + period), not one printf call. Added the fully expanded `%s misses %s.` form, preserving the dynamic argument order.
- `beam.cc:6443` and `5293` use `simple_monster_message` with English suffixes ` appears confused.` and ` is paralysed.`. Added their fully expanded runtime forms to translate the dynamic-name status notifications.
- The ranged miss format at `ranged-attack.cc:224` combines projectile, an optional adverb string that includes a leading English space, and defender. The source-reachable adverbs are empty, `closely`, `barely`, and `completely` (`attack.cc::evasion_margin_adverb`). Added full expanded entries for all three nonempty forms so the English space cannot survive between Chinese captures. The no-adverb form remains covered separately.

The entries are in `localization/luna-combat-review-20261017.json`. Chinese punctuation follows the full line. For printf formats, every `%s` remains in source order; no printf flags or conversions are changed. The suffix-based status entries represent the complete sentence produced by `simple_monster_message`, while the source locations document the actual suffix construction.

The same JSON has a separate `test_cases` array of 18 concrete English-to-Chinese regression oracles. It uses the existing “箭” term, “石头” for the stone missile, and the systematic attack/status wording. The block/reflection cases now also exercise the player/plural base verbs and the invisible-shield punctuation branch. Both source variants `The rat bites you` and `The rat bites you.` are present: the no-period variant expects no punctuation, while the ASCII-period source variant expects the translated output to retain its ASCII period. Observed oracles also preserve the stone-hit ASCII period, use “你遭遇老鼠。” without adding a classifier, and translate the blood-spattered door as “这里有一扇敞开的门，溅满鲜血。” Cases cover arrow and stone hits, miss forms with and without an evasion adverb, repulsion, shield reflection, confusion, paralysis, fire-resistance loss, and the screenshot sentences for encounter, bite, nearby wyvern, blood-spattered door, and three staircases. These are test vectors only and are intentionally kept out of `entries`.

## Boundaries

This audit did not alter fragments used as debug output, targeting syntax, or machine-readable messages. Other status effects are dispatched through shared helpers and require tracing their message-producing implementations individually; this file records the verified high-value combat/status cases above rather than translating every status-related catalog fragment speculatively.
