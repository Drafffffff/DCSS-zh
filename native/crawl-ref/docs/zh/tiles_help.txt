
注意：如果《Dungeon Crawl Stone Soup》的 Tiles 版本运行明显变慢或卡顿，请滚
动到本文末尾查看解决方法。

Tiles 专用指令
-----------------------

你可以通过输入指令按键或使用鼠标，以多种方式与周围环境互动。

屏幕右侧有一组可点击的标签页，可以轻松打开物品栏、法术界面或常用指令，这一点
尤其方便。

根据屏幕分辨率，你可以同时打开其中一个或多个面板。点击标签图标，可以暂时用另
一种 Tiles 面板替换物品栏视图。

可以修改设置目录中 init.txt 的 tile_layout_priority 选项，自定义控制面板的优
先级。

移动
--------

你可以使用方向键、vi 按键或数字小键盘移动。（使用数字小键盘时，请试试
NumLock 开启和关闭两种状态。）

数字小键盘： 7 8 9     vi 按键： y k u
              \|/                 \|/
             4-.-6               h-.-l
              /|\                 /|\
             1 2 3               b j n


想沿同一方向连续走几步，请按住 Shift 再按上述按键。

也可以用鼠标点击地图或小地图上的位置来移动。如果目标格可从当前位置到达，而且
视野内没有敌对怪物，角色就会自动前往那里。如果视野内有敌对怪物，则每次只移动
一步。

自动探索可以输入 `o` 指令，也可以点击屏幕右侧指令面板中对应的图块。与鼠标点
击旅行一样，视野内有敌对怪物时，这些操作都不会启动。

查看信息
-------------------

在主地图或 Tiles 控制面板中的任意地形、怪物或物品上单击鼠标右键，会在单独界
面显示该地形、怪物或物品的说明。

将鼠标移到对象上，通常也会在消息区域显示相同说明，或显示其中能放下的部分。

类似地，将鼠标停在地形、怪物或物品上一会儿，通常会显示包含相关指令的“工具提
示”。

攻击怪物
------------------

使用移动按键走向怪物，或用鼠标点击怪物，即可近战攻击。

进行远程攻击（包括施法和使用魔杖）时，将鼠标移到怪物上并等待工具提示出现。也
可以点击法术面板中的法术图块施法，或点击物品栏面板中的弹药、魔杖来发射或启用
它们。

指令面板中还有一个名为“自动战斗”（Autofight）的图块。点击它会近战攻击相邻怪
物；若旁边没有怪物，则朝最近怪物的方向移动一步。

使用物品
----------

使用物品最简单的方法是在物品栏面板中点击该物品。鼠标悬停提示会说明点击后会执
行什么操作，以及对应的键盘指令。你也可以用 `i` 指令打开物品栏并选中物品，然
后在动作提示中按相应按键。

拾取地面物品时，可以在物品栏面板的地面物品区域逐件点击，也可以点击玩家图块打
开可选物品菜单。使用后一种方式时，按 `Enter` 确认选择并开始拾取。

丢弃物品的操作类似：可以在物品栏面板中逐件点击，也可以输入 `d` 指令，然后从
菜单中选择物品。

与地牢互动
----------------------------

同样，将鼠标移到主地图中的地形（例如楼梯或门）上，工具提示会告诉你如何与它互
动。

角色状态
----------------

在玩家图块上单击鼠标右键，会显示角色概览界面，列出装备、抗性和属性。

点击指令面板中对应的图块，可以查看角色各个方面的详细界面。

角色外观
--------------------

按 `-` 打开纸娃娃编辑器（Doll Editor），即可更改角色外观。按 `m` 切换模式：
装备模式（Equip）会根据你装备的物品动态更新外观；默认模式（Default）会显示基
于角色种族和出身的图像；自定义模式（Custom）允许你完全自定义角色外观的各个部
分。使用数字键切换自定义纸娃娃栏位，使用方向键修改各个自定义角色图像的部件。
按 `Ctrl-S` 保存修改并选中当前外观。


如果遇到明显的卡顿或运行缓慢……
--------------------------------------------------------

《Crawl》使用 OpenGL 和 SDL 绘制图像，但要流畅运行需要硬件加速。如果你使用
Windows，请确保显卡驱动是最新的；如果使用 Linux，请确认已启用 DRI。

游戏已在早至 i865 的显卡上成功测试。不过，已知它在 i810 上运行较慢；这种情况
下，除了改用控制台版本或换一台机器，几乎没有其他办法。

你可以尝试调整设置目录中 init.txt 的若干选项，看看能否改善性能：

travel_delay = -1
    此设置会暂停重绘，直到旅行结束或被打断。

tile_update_rate = 1000
    默认情况下，屏幕至少每 1000 毫秒重绘一次；如果某个动作改变了显示内容，重
    绘会更频繁。可以尝试调高这个值，但这可能导致画面更新延迟过长。

tile_runrest_rate = 17
    角色奔跑或休息时，屏幕每 17 毫秒重绘一次。如果奔跑或休息时《Crawl》运行
    缓慢，可以调高此数值。

tile_tooltip_ms = 0
    停用工具提示后，每次需要绘制的内容会减少。

clear_map = false
    不必重绘视野外已记忆的怪物，可以减轻重绘程序的负担。

tile_window_width   = 1024
tile_window_height  = 768
    地图区域越大，每回合需要重绘的格子就越多。如果你的显示器很大，显示的地图
    远远超过所需的 17x17 格，可以尝试指定较低的分辨率。
