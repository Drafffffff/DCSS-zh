# Target monster localization review

This catalog is a proposal for full target-detail templates and stable semantic atoms. It contains 132 `monster_info_flag_names.long_singular` entries, the 12 damaged/wounded severity atoms from `get_damage_level_string`, the colored wound wrapper, two memory-count variants, constriction direction atoms, target-detail templates, callback combat/encounter logs, semantic pronoun atoms, and 16 auxiliary attack-name atoms, and 11 effect callback descriptors. Every message ID has an explicit independent test case with typed arguments and canonical/localized renderings.

Status IDs use `target.monster.flag.<MB suffix in lowercase>`, preserving the enum identity (for example `MB_HASTED` → `target.monster.flag.hasted`). The English source text remains the complete canonical atom, including `{possessive}` for the two possessive status phrases. The five subjective, five possessive, and five reflexive pronoun forms are represented by semantic IDs under `target.monster.pronoun.*`; Chinese renders the appropriate possessive/reflexive meaning without trying to reproduce English gender distinctions.

Wound atoms distinguish living `wounded` from nonliving `damaged` across all six severity bands. The colored wrapper keeps `<{colour}>…</{colour}>` intact. The prose uses concise target-panel wording; equipment clauses use Chinese word order and punctuation, while the detail join templates preserve their distinct comma, conjunction, and adjacency semantics.

The full templates from `directn.cc` cover target area, behaviour, attitude, aura, creature kind, equipment, attack effects, fire blocking, the monster hover paragraph, and a typed row container. Typed callbacks cover item-use effects, slouch damage, bound-soul HP, marionette spell counts, and pacification chances. The `<<1%` low-chance marker is retained verbatim as markup-escaped source text. The `wearing` item clause uses the general verb `装备着`, suitable for armour, shields, and jewellery. Callback templates cover encounter, pursuit, equipment, throwing, hit chance, and Abyss arrival messages. Auxiliary attack names use exact canonical values from `AuxAttackType::get_name`, and subjective pronouns support the encounter-heads-up callback. The newline join deliberately preserves the line break. Names and values remain typed parameters, so these entries do not match or translate combined English strings by substring.

Translation boundaries: this file does not translate monster names, item names, or feature names; those remain typed `name` arguments. The colored tag names remain markup parameters. Targeting failure reasons and generic targeter prompts belong to their separate catalogs. The `almost dead`/`almost destroyed` pair follows the source distinction between wounded and damaged holiness.
